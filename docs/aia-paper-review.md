# AIAの原論文と実装の照合

## 対象

WangとHanによる論文［1］の本文と，`aia.py` の二つの最小二乗更新を照合した．反復を固定回数で実行する設計は，更新式の誤りとして扱わない．以下では，論文の撮影番号を $`i`$，画素番号を $`j`$ とする．

## 更新式の対応

| 論文 | 実装 | 照合結果 |
| --- | --- | --- |
| 式(1)，(2) | 画像形状 `(steps, ny, nx)` を `(steps, pixels)` に変換し，位相シフトを固定して強度を回帰する | 撮影番号と画素番号の対応は一致する |
| 式(5)〜(8) | `solve(steps, cos(pstep), sin(pstep), axis=0)` | 3 × 3の正規行列と右辺の各和は一致する．行列の逆を明示的に計算する代わりに，`np.linalg.solve` で連立方程式を解く |
| 式(9) | `phase = np.arctan2(-c, b)` | 係数の符号は一致する．`atan2` を用いて象限を扱う |
| 式(10)，(12)〜(15) | `solve(ny * nx, cos(phase), sin(phase), axis=1)` | 画素について和を取る正規行列と右辺は一致する |
| 式(16) | `pstep = np.arctan2(-c, b)[:, None]` | 係数の符号と，画像ごとに位相シフトを更新する処理は一致する |

論文の変調振幅 $`B`$ は，画素ごとの回帰係数から `hypot(b, c)` として求められる．実装が返す `scatt` は，これを平均強度 `a` で割った変調度 $`S=B/A`$ である．したがって，論文の変調振幅と `scatt` を比較する際には，この規格化を考慮する必要がある．

実装の位相シフト初期値は `2π * arange(1, M + 1) / M` である．論文の4枚の数値例では `[0, π/2, π, 3π/2]` を用いるが，両者の差は全画像に共通のオフセットであり，相対位相シフトは同じである．

## 位相シフト推定の仮定

論文のStep 1では，平均強度と変調振幅が撮影画像間で変わらないと仮定する．一方，Step 2では，各画像内で平均強度と変調振幅が一定であると仮定し，画像ごとに新しい三つの係数を求める．Step 1で求めた画素ごとの平均強度と変調振幅は，Step 2では用いない．この点は論文1672頁のStep 2と，1673頁の考察に明記されている．実装も同じ処理となっている．

画素ごとの平均強度と変調振幅を使わないことを，正規化処理の欠落と解釈するのは誤りである．それらを使って強度を正規化すると，論文とは異なる更新式になる．

ただし，Step 2の空間的に一定という仮定を満たさない画像では，位相シフトの推定が偏る場合がある．例えば，32 × 48画素の位相を $`\phi=2\pi x/48+0.2\sin(2\pi y/32)`$，平均強度を $`A=2+0.6\cos\phi`$，変調振幅を $`B=0.4+0.1\sin\phi`$ とし，位相シフトを `[0.2, 1.7, 2.3, 4.1, 5.5]` radとした数値例では，真の位相を回帰に与えても相対位相シフトに最大約1.58 radのずれが生じた．これは実装と論文の相違ではなく，更新式の仮定と入力画像との不一致である．READMEの数値例も平均強度と変調振幅が空間的に変化するため，この仮定を厳密には満たさない．

## 数値検証

空間的に一定の平均強度2，変調振幅0.6と，既知の位相分布から干渉画像を生成し，位相シフトが等間隔でない条件で復元した．撮影枚数は3，4，5枚とした．3枚と4枚の位相シフトには，論文の表2と表1のCase 1の値を用いた．位相分布はテスト用に別途設定しており，論文の表に示された実験全体の再現ではない．

終了条件の違いを除外するため，100回の固定反復で比較した．平均強度，変調度，位相の定数オフセットと符号の曖昧さを考慮した復元位相は，いずれも真値と絶対誤差 `1e-10` 以内で一致した．この確認を `tests/test_aia.py` に追加した．

## 終了条件と出力の扱い

原論文の式(17)は，相対位相シフトの更新前後の差について，画像ごとに絶対値が閾値より小さいことを求める．固定回数で反復する設計は，この終了条件とは区別する．

なお，照合時点の実装には `if err < eps and i > n_iter_min: break` が残っており，既定の引数では厳密な固定回数にはなっていない．本照合の数値検証では，`n_iter_min=n_iter_max=100` として早期終了を無効にした．計算コードの終了条件は変更していない．

また，実装は各反復で画素の成分を求めてから位相シフトを更新し，最後の反復で求めた成分を返す．最後に更新された位相シフトによる成分の再計算は行わない．原論文は収束後にStep 1で位相分布を求めると記述しているため，固定回数の反復でどの段階の値を出力するかは，更新式とは別に定義する必要がある．本照合ではこの出力順序も変更していない．
