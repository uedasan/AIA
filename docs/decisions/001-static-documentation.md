# NotebookからREADMEとPythonスクリプトへの移行

2026-11-14記録．本ブランチで移行を提案し，実装した．

## 背景

本リポジトリでは，WangとHanの論文を参考に実装したAIAの計算と結果の説明を，`AIA.ipynb` にまとめていた．実行には `notebook` をオプション依存として導入していたが，Jupyter関連の間接依存が多く，Dependabotによる更新PRへの対応が継続的に発生していた．

2026-11-14に確認した10件のPRのうち，9件はNotebook環境の依存更新であった．8件を検証してmasterに反映し，JupyterLabとsetuptoolsの個別更新2件は，Notebook更新に伴って不要となったためクローズした．残るPillowの更新は，計算・画像処理にも必要な依存の更新であった．

このリポジトリの目的は，論文を参考にした実装を示し，AIAの処理と結果を説明することである．説明を読むために，Notebookの実行環境を用意する必要はない．数式と計算結果を文書として掲載し，条件を変えて計算する場合にPythonを実行する構成で，この目的を満たせると判断した．

## 移行の内容

解説をREADMEにまとめ，計算関数を `aia.py`，数値例と図の生成を `demo.py` に移した．READMEには，干渉画像のモデル，推定手順，復元結果，誤差および実行方法を記載し，計算を実行せずに結果を読めるようにした．

これに伴い，`AIA.ipynb` とNotebook用のオプション依存を削除し，`uv.lock` を再生成した．計算方法と既定の乱数シードは維持した．今回の変更では，アルゴリズムの改良や専用サイトの構築は行っていない．

元のNotebookはGit履歴に残る．移行前の状態は，コミット `9225a05f04854c741cf13bfcc24559d0d28baab5` から参照できる．

## 保守と利用への影響

ロックファイルに含まれるパッケージ数は，プロジェクト自身を含め111個から20個に減った．図の再現にはPythonスクリプトを用いるため，Jupyterサーバーやカーネルを導入する必要がなくなる．一方，NumPy，Matplotlib，scikit-image，tqdmとその間接依存は引き続き必要であり，これらの更新には対応する必要がある．

Notebookで可能であった，説明とコードをセル単位で変更・実行する使い方はできなくなる．計算条件はコマンドライン引数やPythonコードで変更する．また，READMEに掲載する図は生成済みの画像であるため，計算方法や条件を変更した際には図を再生成し，数値と説明も更新する必要がある．

## 移行時の検証

Python 3.12を用い，移行前のNotebookと同じ条件でシミュレーションを実行した．前景・背景それぞれの平均強度・変調度・位相の6配列と，背景で規格化した3配列について，移行前後の値が許容誤差 `rtol=atol=1e-12` 以内で一致した．

等間隔シフトの解析解に対する成分・位相のテストと，乱数の再現性の計3テストが成功した．既定条件での図の生成に加え，`--step-error 0 --save-arrays` による別条件の図と配列の保存も確認した．

これらは，計算方法が移行前から変わっていないことと，基本的な動作を確認するための検証である．任意の測定条件における収束や精度を保証するものではない．
