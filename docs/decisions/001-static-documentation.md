# NotebookからREADMEとPythonスクリプトへの移行

- 日付：2026-11-14
- 状態：このブランチで提案・実装

## 背景

AIAの計算と結果の説明を `AIA.ipynb` にまとめていた。実行には `notebook` をオプション依存として導入していたが、Jupyter関連の間接依存が多く、Dependabotによる更新PRの対応が継続的に発生していた。

2026-11-14に確認した10件のPRのうち9件は、Notebook環境の依存更新だった。8件は検証してmasterに反映し、JupyterLabとsetuptoolsの個別更新2件はNotebook更新で置き換えられたためクローズした。残るPillowの更新は、計算・画像処理側にも必要な依存だった。

このリポジトリの目的は、AIAの処理と結果を説明し、必要なときに再現できるようにすること。説明を読むために、セルを順に実行できる環境まで用意する必要はない。

## 判断

解説をREADME、計算を通常のPython、結果を生成済みの画像に分ける。

- READMEに画像モデル、数式、反復手順、比較図、誤差、実行手順を掲載する。
- 計算関数は `aia.py`、再現用の処理と図の生成は `demo.py` に置く。
- `AIA.ipynb` とNotebook用のオプション依存を削除し、`uv.lock` を再生成する。
- 計算方法と既定の乱数シードは維持する。アルゴリズムの改良はこの移行と分けて扱う。
- GitHub上で読めるREADMEを入口にする。専用サイトの構築・公開は今回の範囲に含めない。

## 効果と引き換えになるもの

ロックファイルのパッケージ数はプロジェクト自身を含め111個から20個になる。Jupyterサーバー、ブラウザー、カーネルの保守が不要になり、通常のPython実行で図を再現できる。NumPy・Matplotlib・scikit-image・tqdmとその間接依存は引き続き必要なので、依存更新そのものがなくなるわけではない。

一方、説明とコードをセル単位で変更・実行する使い方は失われる。パラメータはコマンドライン引数やPythonコードで変更する。掲載する図は静的なので、コードや条件を変更したときには再生成して数値・説明とそろえる。

元のNotebookはGit履歴に残る。移行前の状態は `9225a05f04854c741cf13bfcc24559d0d28baab5` から参照できる。

## 移行時の検証

Python 3.12で、移行前のNotebookと同じ条件のシミュレーションを実行した。前景・背景それぞれの平均強度・変調度・位相の6配列と、背景規格化後の3配列が許容誤差 `rtol=atol=1e-12` 以内で一致した。

等間隔シフトの解析解に対する成分・位相の単体テストと、乱数シードの再現性の計3テストが成功した。既定条件での図の生成、および `--step-error 0 --save-arrays` による別条件の図・配列保存も確認した。掲載する誤差はこの数値例の結果として示し、一般的な精度保証として扱わない。
